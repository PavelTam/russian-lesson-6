# Бюро времени слов — урок русского языка, 6 класс

Тема: **архаизмы, историзмы и неологизмы**.

Сайт включает иллюстрированную теорию, памятку и тест из 9 заданий:

- 3 задания с картинками;
- 3 задания с выбором одного ответа;
- 3 задания на различение терминов, по три слова в каждом.

Вопросы сразу видны на странице. Проверка возможна по одному заданию или для всего теста. После проверки появляются правильные ответы и объяснения. Результат учитывает первую попытку; есть повторение и сброс. Прогресс хранится только в браузере ученика.

## Публикация

В **Settings → Pages** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**. После завершения сборки GitHub покажет публичную ссылку.

## Запуск без публикации

Скачайте `index.html` и откройте его в обычном браузере. Все стили, картинки и сценарии включены в один файл; установка зависимостей не нужна. Предпросмотр вложения может ограничивать выполнение JavaScript, поэтому для автоматической проверки нужен обычный браузер.

## Учителю

Ориентировочное время: 25 минут. Максимум — 9 баллов; 1 балл за полностью правильное задание с первой попытки. В заданиях на распределение должны быть верно определены все три слова. Это самопроверка, а не готовая школьная отметка.

Новизна слова зависит от эпохи и языковой среды. «Промпт», «дипфейк» и «нейроарт» рассматриваются как новые слова цифровой эпохи. «Стрелец» употребляется в значении воина исторического войска.

Материалы: Валгина, Розенталь, Фомина, «Современный русский язык», §17; справочная служба и журнал «Грамоты.ру». Ссылки приведены в разделе для учителя на сайте. Иллюстрации — авторские схематические SVG.

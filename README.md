# Бюро времени слов

Интерактивный урок русского языка для 6 класса: архаизмы, историзмы и неологизмы.

## Что входит

- Иллюстрированная теория, дополнительные примеры и короткая памятка.
- Девять заданий: три с изображениями, три с выбором ответа и три на распределение слов по группам.
- Режимы «По одному» и «Все задания», переходы по номерам и объяснения после проверки.
- Сохранение проверенных и ещё не отправленных ответов в текущем браузере.
- Итог по первой попытке, повторение заданий и сброс с подтверждением.
- Адаптация для широких и мобильных экранов, клавиатурная навигация и уменьшенное движение.

## Запуск

Сохраните `index.html` вместе с папкой `assets`. Для локального просмотра из этой папки выполните:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/` в браузере. Сборка и установка зависимостей не нужны. Все стили и сценарии содержатся в HTML, иллюстрации — в `assets/`.

## Публикация

GitHub Pages: ветка `main`, корневая папка. Сайт использует относительные пути и работает по адресу репозитория, включая `/russian-lesson-6/`.

## Учителю

Ориентировочное время — 25 минут. Максимум — 9 баллов, один балл за полностью правильное задание с первой попытки. В распределении должны быть верно определены все три слова. Повторение не изменяет первоначальный балл. Это самопроверка, а не готовая школьная отметка.

Новизна слова зависит от эпохи и языковой среды. «Промпт», «дипфейк» и «нейроарт» рассматриваются как примеры цифровой эпохи. «Стрелец» употребляется в значении воина исторического войска.

Материалы: Валгина, Розенталь, Фомина, «Современный русский язык», §17; справочная служба и журнал «Грамоты.ру». Ссылки сохранены в разделе для учителя.

Иллюстрации созданы с помощью генерации изображений и оптимизированы для сайта. Они служат учебными иллюстрациями, а не историческими фотографиями. Описание происхождения — в `ASSETS.md`.
